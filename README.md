# 学习通作业题库整理

本地浏览器扩展（Chrome / Edge，Manifest V3，v1.6.0）。在你本人登录学习通之后，读取课程里**已完成作业**和**已完成章节检测（单元检测）**答卷回看页上已经显示的题目、正确答案、我的答案与解析，按来源分章整理成本地题库，导出 A4 版式 PDF 或可编辑 Word；也可一键下载章节里的 PPT / PDF / 讲义，并按小标题自动命名。面板直接浮在当前页面右上角，可拖动、可收起、可关闭，不打断浏览。

无需输入密码到工具，不需要 API，不自动答题、不提交作业、不猜私有接口、不保存 Cookie 或登录链接，也不调用 AI 生成解析。

## 默认题库版式（用户已确认，未改动）

A4：题干小四号宋体、选项五号宋体、章节标题三号黑体加粗、页码五号宋体居中。每章单独起页，过长自然续页。题目保留全书连续编号，不在每题前重复章节备注。

默认版式：每章末尾集中显示参考答案，按该章题目顺序每 5 题一组，组内标明原题号；不足 5 题按实际数量显示。题后不直接显示正确答案或我的答案。题目原文异常说明、已采集解析一并放入章末答案区。

如果更希望边看题边看答案，可在导出面板把「答案位置」切换为「紧跟题目」，答案与解析会直接排在对应题目下面（PDF 与 Word 同步生效）。

## 1.6.0 更新：界面收敛

功能与数据格式不变，只重做视觉与信息层级，让面板更像一件工具而不是一张表单。

- **去掉卡片堆叠**：三块内容改为「细分隔线 + 小标题」，少一层边框、少一层阴影，纵向更紧凑。
- **一个视觉焦点**：主操作（扫描、导出 PDF）用深墨色实底按钮，其余为描边或纯文字按钮；禁用态只降透明度，不再变色块。
- **状态只占一行**：原来的浅绿底块改为左侧一条 2px 竖线，长文本才滚动，页面更安静。
- **输入更轻**：输入框与下拉改为填充式（无边框），聚焦时才出现描边与柔和光晕。
- **说明集中**：原先分散在采集、导出、课件三处的长文案合并为一个「使用说明」折叠项，默认收起；折叠标记统一为小三角。
- **列表渐进披露**：课件行的操作按钮平时半透明，悬停或键盘聚焦时显现；触屏设备始终显示。
- **浮层外壳**：标题栏压到 38px、纯白无渐变、投影更柔，关闭按钮悬停转为警示色。
- 字号、行高、圆角、间距统一收敛到一套变量；窄屏（≤520px）按钮放大到 38px，字段整行排列。

## 1.5.0 更新：面板改为页面内浮窗

以前点扩展图标会新开一个标签页，采一份就要在「学习通」和「面板」之间来回切，浏览流程被打断。

现在点图标会在**当前学习通页面的右上角浮出一块面板**：

- 面板是独立的浮层（Shadow DOM + 扩展页 iframe），不遮挡点击、不影响页面原有脚本，可拖动标题栏移动位置，可「–」收起成一条标题栏，可「✕」关闭；位置会记住，下次打开回到原处。再点一次图标即关闭。
- 窄屏或手机宽度下自动变成底部抽屉，宽度跟随视口，按钮加大到适合手指点击。
- 打开面板会**自动识别当前页**，省掉一次「扫描当前页」；按钮随后变成「重新扫描」。识别到章节学习页时会顺手扫描课件附件。
- 面板重新排过版：状态条居首，采集 / 导出 / 课件三张卡片只留一行核心操作，长篇说明收进「页面信息」「说明与诊断」等折叠项，日志默认折叠；表单控件统一高度、按钮分主次（扫描、导出 PDF 为实心主按钮）。
- 在无法注入的页面（`chrome://`、扩展商店、非学习通站点）点图标，仍和以前一样打开独立标签页，功能完全一致。

首次升级请在扩展管理页点「重新加载」，然后刷新学习通页面；旧标签页面板可以关掉。

## 1.4.1 修复：认出 /ananas/status 是文件清单接口

1.4.0 仍有一个漏点：文档查看器发出的第一条请求是

```
https://mooc1.chaoxing.com/ananas/status/<objectid>?flag=normal&_dc=...
```

它返回的是 **JSON 清单**，里面才有真正的 `download`（原文件）与 `pdf`（转码副本）地址。上一版把它当成文件地址去下，结果自然还是网页。

- 扫描时会把 `/ananas/status/<id>` 里的 `objectid` 一起提取出来，与 `/star3/origin/<id>` 合并成同一个附件。
- 下载前先读这份清单：先试扩展页读取，失败再在页面内读取（页面请求带着查看器自己的 Cookie 与 Referer）。取到 `download` 后排在候选第一位，`pdf` 备用。
- 清单里的 `filename` 也用来校正扩展名，命名依然用小标题。
- 状态列从「待验证 / 待解析 / ✓ 已下载 / ✗ 没下成」四态显示，便于判断卡在哪一步。
- **小标题**：目录高亮项的识别选择器扩充了一批旧版写法；页面确实拿不到时用附件名兜底（去掉 `(1)` 这类重复标记），多附件时不会把标题拼两遍。

## 1.4.0 修复：课件下成网页 / 打不开

上一版用 `https://p.ananas.chaoxing.com/star3/origin/<objectid>`（不带扩展名）当直链。这个地址在学习通上返回的是一张**网页**，Chrome 按响应类型把它存成了 `.htm`，所以下载下来「根本不是课件」。

1.4.0 改成「先验证再保存」：

- **地址候选**：从页面收集每个附件的若干候选地址，按可信度排序——页面真实请求过的（带 `flag=` / `.pdf` 的完整 URL）> 带文档扩展名的 > 自己拼的 `<objectid>.<扩展名>` > `<objectid>?flag=1`。不再把不带扩展名的裸地址当首选。抓取来源也扩大了：`AttachmentSetting` 里任意键（`url` / `download` / `pdf` / `fileUrl`…）、iframe 查询参数、页面内联脚本里的文件地址，并提高了 `performance` 记录上限。
- **逐个验证**：下载前先发一次 1 字节的探测请求读 `Content-Type`；返回 `text/html` / `application/json` / 图片的直接跳过。下载完成后再用 `chrome.downloads` 的 `mime` 与文件大小复查，是网页就删掉该文件并自动换下一个候选。
- **类型与命名**：扩展名改由真实响应决定（`Content-Disposition` > `Content-Type` > 元数据），所以不会再出现「名字是 .pdf、内容是网页」。
- **兜底通道**：若所有候选都被服务端拒绝（通常是防盗链），改为**在页面内用页面自己的 Cookie / Referer 取回**，交给临时链接触发下载；这一份只能落在「下载」根目录，日志里会写明。
- **手工直链**：面板新增「粘贴直链」，把 F12 → Network 里带 `flag` / `.pdf` 的地址贴进来，走同一套验证与命名流程。每行「复制直链」会先验证再复制。
- **提示**：扫描前先在页面里翻到第 2 页 PPT，让浏览器真的请求过一次课件，`performance` 里才会留下最可靠的直链。

## 1.3.0 新增：章节课件下载（PPT / PDF / 讲义）

章节学习页（能翻页看 PPT 的那一页）的「课件」区可以批量下载本章节附件，不必再按 F12 翻 Network 找 `flag` 链接。

- **来源**：只读页面自己已经持有的附件信息——卡片页的 `AttachmentSetting`、附件 iframe 的 `data`、指向文件的链接，以及文档查看器已经发出的请求记录（`performance`）。不发新请求、不调接口。
- **命名**：以目录里的小标题为准，例如 `1.1 绪论.pdf`；同一小标题下有多个附件时变成 `1.1 绪论_讲义.pdf`，重名自动编号。小标题可在面板里改，改完点空白处生效。
- **位置**：`下载 / 学习通课件 / <课程编号> /`。同名文件自动加序号，不覆盖已有文件。
- **筛选**：默认只下文档（pdf / ppt / pptx / doc / docx / xls / xlsx / zip 等），视频与音频需勾选「也下载视频 / 音频」；列表里仍会显示它们。
- **累加**：一页有多张卡片时，切换卡片后再点一次「扫描本页」，同 `objectid` 自动去重累加。

## 1.2.6 修复：换单元后不再夹带上一个单元的题

之前的归档按课程存，导出「只导章节检测」时会把所有采过的单元合并进同一份文件。采集第二、第三个单元时，前面单元的题仍在题库里一起被导出。

现在导出面板新增「章节检测来源」：

- **最近采集**（默认）：只导出刚刚采集的那一份检测；换单元采集后自动切换，不会带上别的单元。
- **全部已采集检测**：需要整门课的总题库时再选，行为与以前一致。
- 也可以直接点选某一份单元检测单独导出。

同时采集端也加了章节校验：只保留属于当前打开章节的检测帧，其他章节的帧会被忽略并在状态栏说明，避免页面里残留的旧检测被一起写入。选中单份检测导出时，文件名直接用该检测的标题（如「第三单元 传染病防治法律制度-单元检测」），不再叫「课程XXXX题库」。

## 1.2.5 新增：答案位置可选（章末集中 / 紧跟题目）

导出面板新增「答案位置」下拉，两种版式都同时作用于 PDF 与 Word：

- **章末集中（默认）**：保持已确认的版式，每章末按 5 题一组列出正确答案，解析跟在答案后面。适合先做题、再对答案。
- **紧跟题目**：每道题下面直接排「正确答案（含我的答案与历史错题标记）→ 解析（含解析配图）→ 核对备注」；不再输出章末参考答案区。适合背诵和通读。

选择会记在本机，下次打开面板仍然是上次的设置。「显示解析」仍然只控制解析是否输出，不影响答案。紧跟题目模式下，预览里的「显示答案」开关会同时隐藏每题下的答案块。

## 1.2.4 修复：65 题只认出 8 题

拿到真实答卷页结构后确认：每道题就是一个 `div.TiMu` 卡片。题干在 `.qtContent`，选项在 `.qtDetail li`（`i` 存字母、`a` 存文字），我的答案 `.myAnswer .answerCon`、正确答案 `.correctAnswer .answerCon`、解析 `.answerKeyBx .answerCon`、知识点 `.knowledgePointBx .knowledgeList li`、分值 `.scoreNum`。

1.2.3 靠「正确答案」文本向上找容器，会一路爬到多道题的共同祖先，同一页 65 题被反复解析成同一批卡片，再去重就只剩个位数。

现在优先**按 DOM 选择器逐卡采集**（`.TiMu`，旧版 `.questionLi` 同样兼容），一卡一题，题号直接取卡片上的 `i`；只当页面里完全找不到题卡时才退回文本状态机。同一章节课页挂了多份单元检测（例如 65 题与 39 题各一份）时，现在会**全部保存**，不再只留最长的一份。

同时修正图片过滤：真实题目图片在 `p.ananas.chaoxing.com/star3/...`，旧规则把含 `star` 的地址当成图标丢弃，含图题会丢图。

## 1.2.3 修复：导出的选项错位、解析丢失

真实答卷页的 `innerText` 不一定按「A. 选项文字」输出：选项字母和文字、题号和题型、标签和值都可能各占一行。1.2.2 的逐行状态机因此把碎片拼错，导出成 `A. B.` `C. D.`，解析也整段丢失。

现在改成两遍解析：

1. **按文本锚点切题卡**：以「正确答案」为锚点向上找到「恰好只含一份答案区」的最小容器，这个容器就是一道题。题目边界不再靠猜。
2. **按标记位置切片**：在题卡文本里按 `A.` `B.` `C.` 标记的位置取区间，标记之间的文本就是选项内容，与换行无关；题干取第一个选项标记之前的文本；`我的答案 / 正确答案 / 答案解析 / 知识点 / 分值` 各用正则取值。解析区里的 `A.` 不会再被当成选项。
3. 逐行状态机保留为兜底，题卡锚点失效时才启用。

## 1.2.1 / 1.2.2 修复：页面明明打开却采不到

- **放开严格题量校验**：分页 / 懒加载的答卷页只渲染一部分题目时，不再直接拒绝保存；改为保存已采部分并提示「累计 X 题 / 页面标注 Y 题」，再次采集**按题号合并**。
- **修复同一行多个标签**：真实页面常把「我的答案：A 正确答案：A ✓1.5分」放在同一行（标签在 span 里，innerText 不换行），旧逻辑会把「A 正确答案：A」整段当成我的答案、导致正确答案为空。现在按标签拆分，并自动剥离行尾分值。
- **针对 innerText 分行重写预处理**：题号「1」、题型「【单选题】」、题干、选项字母「A」、标签「我的答案」在部分版本里各占一行，旧逻辑要求它们同行，于是整页 0 题。现在先归并成 `1【单选题】题干`、`A. 选项`、`我的答案：A` 再解析。
- **题号缺失兜底**：若题号由 CSS 绘制、文本里根本没有数字，改为按题型徽标顺序自动编号。
- **采集失败自动留证**：识别失败时把页面结构写入面板诊断区，点「诊断」即可复制反馈；浮层标题栏显示当前版本号（v1.6.0），便于确认是否已重新加载。
- **放宽格式兼容**：题号支持 `1.【单选题】`、`1、`、`1．`、`1）`、`第1题`；分节标题兼容半角 `(共65题)`；一行内出现多个选项时会拆开。

## 1.2.0 新增：章节检测导出

- 新增「采集当前章节检测」：打开某单元检测的**答卷回看页**（能看到「我的答案 / 正确答案 / 答案解析 / 知识点 / 分值」的那一页），滚动到页面底部等题目全部加载，点一下即采集一份。
- 采集器优先读题卡 DOM（`.TiMu` / 旧版 `.questionLi`），逐卡取题干、选项、答案、解析、知识点与图片；找不到题卡时才退回可见文本的行结构解析，题目/解析图片按题卡归属。
- 检测入口只使用**页面自己给出的链接**。章节目录里的「X.3 第三部分 单元检测」多为 `javascript:void(0)` 脚本跳转，插件不自行拼接 URL；因此批量采集方式仍是「逐章点开 → 采集一次」。
- 不点击「AI 讲解」，不采集 AI 生成内容；只取平台原有「答案解析」。
- 章节检测与作业**分开归档**（`quiz-<课程编号>` / `course-<课程编号>`），避免编号碰撞；导出时可选择「全部合并 / 只导作业 / 只导章节检测」，合并时同题会自动去重并合并来源。
- 整理面板新增课程编号输入、页面类型识别、采集统计和「复制页面诊断信息」按钮；页面改版导致识别失败时，可复制诊断信息用于适配。
- 分级校验：题量与页面标注一致时标记为完整；页面**分页或懒加载**只渲染一部分时，照样保存已采到的题目，并明确提示「累计 X 题 / 页面标注 Y 题」。翻页或滚到底后再点一次「采集当前章节检测」，会**按题号自动合并**，不会覆盖已采部分，也不会静默生成缺题题库。未公布答案标「待核对」；选项识别不全会在章末加核对备注。
- 修正 1.1.0 中针对单一课程的硬编码错别字规则，改为通用检测；多选题答案 `AB` 与 `BA` 不再被误判为错题。

1.1.0 的 PDF / Word / 解析开关能力全部保留：预览里「显示解析」可再次切换；Word 直接下载真实 `.docx`（A4、章节分页、动态页码）；压缩包内已包含 Word 生成库，使用者无需 Node.js 或联网下载依赖。

`学习通题库插件_图文使用说明.docx` 仍是 1.1.0 的界面截图说明，本次未同步；安装与操作请以本 README 为准。

## 安装扩展（一次）

1. 解压本目录并保留在固定位置。
2. 在 Edge 地址栏打开 `edge://extensions`；Chrome 使用 `chrome://extensions`。
3. 开启「开发人员模式」，选择「加载解压缩的扩展」，选中本目录里的 **extension** 文件夹（里面有 manifest.json）。
4. 权限只有 `scripting`、`storage`、`downloads`，主机权限 `https://*.chaoxing.com/*`；浏览器会显示对应权限。`web_accessible_resources` 只把面板自己的页面与脚本暴露给学习通域名，供浮层内的 iframe 加载。
5. 从 1.1.0 升级：用新 `extension` 覆盖原文件夹，在扩展管理页点「重新加载」，关闭旧整理面板再重新打开。无需卸载，原归档可保留。

## 日常使用

### A. 已完成作业（原有流程）

1. 在安装扩展的同一浏览器中登录学习通，进入课程，点击「作业」，等待完整列表出现。
2. 点击工具栏扩展图标，面板浮在页面右上角并自动识别当前页 → 确认列出的作业范围 → 「已完成作业」。采集时可以把面板「–」收起，不必关闭。
3. 重复运行按作业编号替换旧记录；失败的作业记录错误并保留旧版，请查看失败数。列表有分页时逐页运行。

### B. 章节检测 / 单元检测（新增流程）

1. 进入课程「章节」，点开某个已完成「单元检测」，进入能看到「我的答案 / 正确答案 / 答案解析」的答卷回看页。
2. **滚动到页面底部**，等待全部题目渲染完成（题目常为懒加载）。
3. 点扩展图标，面板浮出并已自动识别 → 「本章检测」。状态栏会显示本次题数与含解析题数。
4. 换下一章，重复 1–3。每份按检测编号覆盖更新，不会重复堆叠。
5. 状态栏若出现「累计 X 题 / 页面标注 Y 题」，说明这一页只渲染了部分题目（分页或懒加载）：翻到下一页或滚到底后再点一次采集，插件按题号合并，已采部分不会丢。
6. 若提示「识别失败」，先确认答案与解析确实已显示；仍失败则点「复制页面诊断信息」，把内容贴给开发者适配新版结构。面板状态栏会显示识别到的检测份数、每份题数与页面标注题数。

### C. 下载章节课件

1. 在学习通打开某一章节（能翻页看 PPT 的页面），等页面与文档加载完。
2. **先在页面里翻到第 2 页**（或往下翻一页），让浏览器真的请求一次课件文件——这一步决定直链是否准确。
3. 点扩展图标 → 「课件」卡片 → 「扫描本页」（章节页打开面板时会自动扫一次，可直接看结果）。
4. 核对列表里的文件名（小标题）与类型，必要时改「小标题」。
5. 「下载全部」或逐行「下载」；文件在 `下载/学习通课件/<课程编号>/`。

每行会显示 `待验证 / ✓ 已下载 / ✗ 没下成`。插件对每个附件会按顺序试多个地址，遇到「服务器返回网页」会自动删掉错文件并换下一个；全失败时日志会列出每条地址被服务端拒成了什么类型。此时用「粘贴直链」把 F12 → Network 里带 `flag` / `.pdf` 的地址贴进来即可。

### D. 导出

在「导出范围」中选择全部合并 / 只导作业 / 只导章节检测，在「章节检测来源」中选择最近采集的一份、全部检测或指定某一单元，勾选是否「显示解析」，再点「导出 PDF」或「导出 Word」。面板会在按钮上方写明「本次将导出哪几份、多少题」。

换单元采集后，来源会自动切到新采的那一份，默认不会把上一个单元的题混进同一份题库。

- PDF：预览页点「打印 / 另存为 PDF」，纸张 A4、缩放 100%、关闭浏览器自带页眉页脚。
- Word：直接下载 `.docx`，用 Word / WPS 打开；宋体、黑体需本机安装。

## 适用范围与限制

- 作业采集仍只针对学习通 `.questionLi` 结构（单选 / 多选）验证；章节检测采集基于可见文本格式，已在模拟答卷页与真实外壳页面结构下通过测试，但**题目详情位于 iframe 内层，尚未实机验证**。
- 章节检测需页面已公布答案与解析。若答案要点击才展开，请自己点开后再采集；插件不代点、不触发额外请求。
- 课件下载只处理你自己账号下、页面上已有入口的附件；不遍历未开放的资源，不做整站抓取。判定依据是服务端真实返回的 `Content-Type`，不是文件后缀，所以不会再出现「.pdf 里装的是网页」。若某个文件仍下不来，先用该行「复制直链」在浏览器里验证；还不行就用「粘贴直链」手工指定。
- 未完成作业、未完成检测、考试、自动答题和提交不在范围。填空题、复杂公式、特殊图片格式尚未适配。
- 同一章节课页可能挂了多份单元检测（如「第一单元 卫生法基础知识-单元检测」65 题与「基本医疗卫生与健康促进法 单元检测」39 题），采集时会一同保存；导出时用「章节检测来源」指定要哪一份，避免混排。
- 未公布答案会标记待核对；题量或题干读取异常不会静默生成缺题结果。
- PDF 预览会检查可见图片是否加载；Word 只嵌学习通 HTTPS 的 PNG/JPEG/GIF（每张 ≤10 MB），失败明确报错，不默默丢图。解析图片同样处理。
- 遇到验证码或登录过期，在来源浏览器处理后重试；工具不绕过验证。
- 课程编号通常从页面 URL 自动读出；若读不到，请在面板手动填写，否则无法归档。更换学习通账号请先移除并重新加载扩展以清空旧归档。
- 页面改版需重新适配：优先用「复制页面诊断信息」得到的新结构修订 `extract.js` 的解析规则。

## 源码结构

不需要构建即可加载 `extension/`。开发验证需要 Node.js：

```text
node --test test.mjs
```

| 文件 | 职责 |
|---|---|
| `extension/manifest.json` | MV3 配置与权限 |
| `extension/background.js` | 点击图标：学习通页面注入浮层，其他页面回退到独立标签页；并回答浮层所需的标签页 ID |
| `extension/overlay.js` | 注入页面的浮层：Shadow DOM 外壳、拖动 / 收起 / 关闭、位置记忆、窄屏底部抽屉、iframe 承载面板 |
| `extension/dashboard.html/css/js` | 扫描、双来源采集、归档、导出调度、诊断复制；同一份页面同时服务浮窗与独立标签页（`?embed=1`） |
| `extension/extract.js` | 注入页面的自包含函数：作业发现/提取、页面类型识别、章节目录发现、章节检测解析、课件附件扫描、页面内取回文件、页面诊断 |
| `extension/core.mjs` | 校验、去重合并、连续编号、按来源分章、HTML/CSV 生成与打印样式 |
| `extension/documents.mjs` | 课件下载的纯逻辑：扩展名判断、小标题命名、候选地址排序、`Content-Type` 分类、去重、保存路径 |
| `extension/print.html/js` | 经 `chrome.storage.session` 传递一次性任务，渲染 PDF 预览并检查图片 |
| `extension/word.mjs` + `vendor/docx.mjs` | 内置 Word 生成库，离线打包真实 `.docx` |
| `test.mjs` | 纯 Node 单元测试，含模拟章节检测答卷页 |
